Connection Settings

Configure how QR LIS talks to lab analyzers. Every method below writes to the same /api/instruments list used across the app — add one here and it immediately shows up in Booking → Branch → Analyzer, and can start receiving results.

ASTM (E1381 / E1394)

Classic message format (Header/Patient/Order/Result/Terminator). Usually carried over Serial or a TCP session.

HL7 v2.x / FHIR

Modern standard for LIS/HIS/Middleware integration. Carried over TCP/IP (MLLP) in almost all cases.

TCP/IP (Ethernet)

Direct network link — set a fixed IP and port. Fastest to set up on modern analyzers.

RS-232 (Serial)

Legacy cable/COM-port link for older analyzers. Needs matching Baud/Parity/Stop-bits.

Middleware

Data Innovations Instrument Manager, Beckman REMISOL Advance, etc. — unifies several analyzers into one feed.
