QR LIS — نشر على الإنترنت (Deploy)
=====================================

المشروع ده جاهز للرفع على أي خدمة استضافة بتشغّل Node.js. الخطوات هنا
مكتوبة لخدمة Render.com لأنها بسيطة وليها باقة مجانية، بس نفس الفكرة
تنفع مع أي خدمة تانية (Railway, Fly.io, ...).

⚠️ تنبيهات مهمة قبل ما تبدأ
-----------------------------
1. البرنامج بقى فيه تسجيل دخول حقيقي لكل شخص (يوزر/باسورد خاص بيه + صلاحية
   حسب دوره)، بدل الباسورد المشترك القديم. أول تشغيل بيحوّل QRLIS_USER/
   QRLIS_PASS تلقائيًا لأول حساب Admin — سجّل دخول بيه مرة واحدة، وبعدها
   اعمل حساب باسم كل شخص فعلي من Administration → User Accounts، وغيّر/
   عطّل الحساب المشترك ده. غيّر كمان QRLIS_USER/QRLIS_PASS في متغيرات
   البيئة لحاجة قوية (مش admin/changeme123) قبل أول نشر.
2. الباقة المجانية في Render:
   - مفيهاش تخزين دائم (Persistent Disk) — يعني لو السيرفر أعاد التشغيل
     (بيحصل تلقائي بعد فترة عدم استخدام) البيانات المحفوظة ممكن تتصفّر.
     ده مناسب للتجربة، مش لبيانات مختبر حقيقية دايمة. لو عايز تخزين
     دائم فعلي، محتاج تترقّى لباقة مدفوعة فيها Persistent Disk، أو
     ننقل التخزين لقاعدة بيانات حقيقية (Postgres مثلاً) — قولّي لو
     عايز الخطوة دي وقت ما توصلها.
   - السيرفر المجاني "بينام" بعد ~15 دقيقة من غير استخدام، وأول طلب
     بعد كده بياخد شوية ثواني إضافية يفوق بيها.

خطوات النشر على Render.com
-----------------------------
1. اعمل حساب مجاني على https://render.com (تقدر تسجل بحساب GitHub مباشرة).

2. ارفع المجلد ده على GitHub:
   - اعمل repository جديد فاضي على github.com
   - من جوه المجلد ده، في Terminal:
       git init
       git add .
       git commit -m "QR LIS"
       git branch -M main
       git remote add origin <رابط الـ repo بتاعك>
       git push -u origin main

3. في Render: New + → Web Service → اختار الـ repo اللي رفعته.

4. الإعدادات:
   - Runtime: Node
   - Build Command:  npm install
   - Start Command:  npm start

5. تحت Environment Variables ضيف:
   - QRLIS_USER = اسم مستخدم من اختيارك
   - QRLIS_PASS = باسورد قوي من اختيارك

6. دوس Create Web Service. بعد كذا دقيقة هيديك رابط زي:
       https://qrlis-xxxx.onrender.com
   ده الرابط اللي تفتحه من أي جهاز في العالم — هيطلب منك اليوزر
   والباسورد اللي حطيتهم فوق.

ربط مستقبل الأجهزة (HL7 Listener) بالنسخة المنشورة
-----------------------------------------------------
لو عايز جهاز المختبر (اللي شغّال عليه qrlis-hl7-listener.exe) يبعت
نتايج على النسخة المنشورة على الإنترنت بدل الشبكة المحلية، شغّله كده:

    set QRLIS_USER=نفس-اليوزر-اللي-حطيته-فوق
    set QRLIS_PASS=نفس-الباسورد-اللي-حطيته-فوق
    qrlis-hl7-listener.exe 5100 https://qrlis-xxxx.onrender.com

(الأوامر دي في Command Prompt على ويندوز، قبل ما تشغّل الملف في نفس النافذة)
